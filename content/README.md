# Local Content Workspace

Generated records are private by default and excluded from version control.

| Directory | Purpose |
| --- | --- |
| `ideas/` | Raw and clarified experience records |
| `drafts/` | Researched and optimized drafts awaiting approval |
| `approved/` | Exact approved versions and approval hashes |
| `metrics/` | 24-hour and 7-day performance snapshots |
| `reviews/` | Monthly performance reviews and experiments |
| `media/` | Local images and documents used in posts |

Use [calendar.template.md](./calendar.template.md) to plan 1–2 posts per week. Do not place credentials, tokens, or unapproved confidential information anywhere in this workspace.
